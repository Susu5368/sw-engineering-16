# 클래스: 귀가시간계산

| 항목 | 내용 |
|---|---|
| 파일 | classes/ReturnHomeTimeCalc.md |
| 종류 | 공통 객체 (기능 15, 20) |
| 상태 | 추가 |
| 설명 | 학생의 현재 위치와 자택 위치로 추정 이동 시간(분)을 계산한다 |

## 속성

| 가시성 | 이름 | 타입 | 설명 |
|---|---|---|---|
| - | 굴곡계수 | double = 1.3 | 직선거리 → 추정 도로 거리 |
| - | 도보기준거리 | double = 1.5 | km, 이하이면 도보 |
| - | 도보속도 | double = 4 | km/h |
| - | 차량속도 | double = 25 | km/h, 심야 차량 |

## 연산

| 가시성 | 시그니처 | 사용처 |
|---|---|---|
| + | 이동시간추정(학생ID: int): int | seq-20 #8, seq-15 (작성 예정) |
| - | 이동시간계산(현재위치: Point, 자택위치: Point): int | seq-20 #11 |

- 이동시간추정은 위치를 얻지 못하면 -1을 돌려준다.

## 관계

| 대상 | 종류 | 다중성 | 근거 |
|---|---|---|---|
| 단말기위치정보 | 연관(→) | 1 → 1 | seq-20 #9 |
| 프로필DB | 연관(→) | 1 → 1 | seq-20 #10 |
| Point | 의존(┄▶) | | #9, #10 반환값, #11 매개변수 |
